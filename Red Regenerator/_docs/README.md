# Red Regenerator — End-User Documentation

Guides for end users of the Red Regenerator extension.

- [Contracts](contracts.md) — what a contract is, its lifecycle and status flow, and the actions available on it (Accept, Activate, Regenerate, Renew, Close, Cancel).
- [Creating Contracts](creating-contracts.md) — the ways a contract comes into existence: manually, or automatically from a Contract Template when an item/account/resource ships or is received.
- [Contract Groups and Setup](contract-groups-and-setup.md) — company-wide setup (number series, auto-archive behavior) and Contract Groups (Order vs. Invoice regeneration).
- [Linking Sales and Purchase Contracts](linking-sales-and-purchase-contracts.md) — tying a purchase contract to the sales contract it's billed against.
- [Archiving Contracts](archiving.md) — archive reason codes and when contracts are archived automatically.
- [Item Contracts](item-contracts.md) — automatically add a recurring contract line when an item is sold, and how to set up or bulk-create item/contract mappings.
